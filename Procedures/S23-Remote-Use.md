# Using VCDS with the Samsung Galaxy S23

The genuine Ross-Tech HEX-V2 does not run full VCDS directly on Android.

The supported practical arrangement for the existing equipment is:

Car -> HEX-V2 -> Windows laptop running VCDS

The Samsung Galaxy S23 may then be used to remote-control the Windows laptop if useful while moving around the vehicle.

This preserves the full Windows VCDS environment while allowing the phone to act as a convenient remote screen/controller.
