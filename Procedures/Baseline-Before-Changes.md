# Baseline Procedure Before VCDS Changes

For either the Golf or Polo:

1. Connect the genuine HEX-V2.
2. Run VCDS on the Windows laptop.
3. Perform a complete Auto-Scan.
4. Save the scan before clearing anything.
5. Preserve freeze-frame data where available.
6. Record Advanced Identification where useful.
7. Export adaptation maps for modules that may be changed.
8. Record the original coding/adaptation value.
9. Make only the intended logical change.
10. Test the function.
11. Rescan.
12. Record whether the change was kept or reverted.

Avoid broad speculative coding changes.

Avoid global fault clearing until the original diagnostic information has been preserved.
